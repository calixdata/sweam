# Sweam brand assets

Place the Sweam wordmark here as `sweam-wordmark.png` (the temporary logo: black
letterforms with blue wave and play-button accents on white).

Guidelines for use in this repo:

- Any embed of the wordmark must carry alt text: `Sweam wordmark: the word
  Sweam in bold black letters with blue wave accents; the A contains a play
  button.`
- UI chrome uses the text brand (see `.brand` in `apps/web/src/styles.css`)
  rather than the image, so the header stays crisp at any zoom level and reads
  correctly in screen readers.
- Palette drawn from the mark: background `#0b0d12`, accent blue `#2f6df0`,
  highlight `#35c7f0`.
