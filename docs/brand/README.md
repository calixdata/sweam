# Sweam brand assets

`sweam-wordmark.png` is the Sweam wordmark: black letterforms with blue wave
and play-button accents on white.

Guidelines for use in this repo:

- Any embed of the wordmark must carry alt text: `Sweam wordmark: the word
  Sweam in bold black letters with blue wave accents; the A contains a play
  button.`
- The web app serves it from `apps/web/public/brand/sweam-wordmark.png` and
  seats it on the dark header inside a white chip (see `.brand-img` in
  `apps/web/src/styles.css`) with a text fallback if the asset fails to load.
- Palette drawn from the mark: background `#0b0d12`, accent blue `#2f6df0`,
  highlight `#35c7f0`.
